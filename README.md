# BellyCarry

BepInEx multiplayer mod for Casualties: Unknown that presents KrokMP player carries as a Consumed-style belly carry.

The interaction menu includes a separate **Vore** button beneath the native
Carry/Piggyback/Push row. Native Carry remains available for ordinary
transport; Vore attaches the selected player and synchronizes the belly state.

Build with `../build.sh BellyCarry`. Local two-instance testing is documented in `../docs/local-coop.md`.
